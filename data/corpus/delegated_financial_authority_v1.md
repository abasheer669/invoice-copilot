# Delegated Financial Authority Matrix - Superseded

This version is retained for historical audit only and must not be used for current approvals.

The old limits were AUD 5,000 for Cost Centre Managers, AUD 25,000 for Department Directors, AUD 100,000 for Executive Directors and AUD 500,000 for the CFO. It did not require Financial Control co-approval for a new overseas account.

Current decisions must use FIN-POL-003 version 4.0 or later. A retrieval system should rank current policy above this document and expose its superseded status.
